# 作品集在线后台：下一步方案

## 当前已完成

- 10 个项目文档与可校验导入/导出。
- 本机 `/admin`：分字段编辑、草稿保存及备份、素材上传、同步本地预览。
- 本地事件计数及 JSON 导出；生产构建不发送本地事件。

## 在线版需要确认的连接

1. 当前部署平台和希望使用的站点域名。
2. 后台登录账号；选择一个有服务端运行环境的部署方式。
3. 存储图片/视频的云存储，以及内容数据库或 Git 仓库。
4. 统计范围：访客、页面访问、项目转化、简历下载点击等。

不在未选择服务前创建外部账号、开通付费服务或上传素材。

## 建议的在线功能范围

- 管理员登录、权限校验；敏感内容在服务端校验后返回。
- 项目新增、排序、隐藏、草稿、预览和发布。
- 文案与章节编辑，素材库，图片/视频类型与顺序。
- 每个项目的密码独立管理；服务端保存密码哈希，限制错误尝试，使用有过期时间的会话。
- 素材访问同样鉴权，不能只遮住页面却暴露图片 URL。
- 统计页面访问、项目入口、解锁成功、简历/邮箱/LinkedIn 点击；不记录密码或表单内容。
- 区分测试/管理员流量和真实访客，设置数据保留时长、导出与删除。
- 发布前校验素材与链接，保留内容版本和恢复入口。

## 数据结构

项目：稳定 ID、slug、名称、类别、年份、角色、标签、封面、状态、排序、章节。

章节：项目 ID、类型、标题、文案、素材数组、顺序。

素材：项目 ID、文件名、MIME 类型、尺寸、存储键、访问权限。

事件：事件类型、项目 ID、时间；如果需要独立访客指标，再确定匿名标识和告知方式。

本机版本是可用的内容工作台，不能直接当成公开网络中的安全后台部署。
